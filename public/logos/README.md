# Logos for the Accreditations & Clients sections

Drop the logo image files here with the **exact filenames** below. The homepage
sections detect them automatically — if a file is present it shows the logo, if
not it falls back to a text badge. No code changes needed.

## Accreditations & Memberships

| Filename | Logo | Notes |
|---|---|---|
| `supply-nation.png` | Supply Nation **Registered** badge | Use the official "Registered" badge Supply Nation gave you (NOT "Certified") |
| `nswicc.png` | NSW Indigenous Chamber of Commerce | Member logo from your NSWICC membership pack |
| `pibng.png` | Pilbara Indigenous Business Network Group | Member logo from PIBNG |
| `ntibn.png` | Northern Territory Indigenous Business Network | Member logo from NTIBN |
| `kdcci.png` | Karratha & Districts Chamber of Commerce & Industry | Member logo from KDCCI |

## Clients

| Filename | Logo | Notes |
|---|---|---|
| `coforge.png` | Coforge | Only if Coforge is OK being shown as a client |

**Government departments are intentionally NOT logos.** The Commonwealth Coat of
Arms is legally protected and must not be reproduced as a client logo without
authorisation, so Home Affairs / Health are shown as **text names only**. Do not
add government crest images here.

## File specs
- **Format:** PNG with a **transparent background** (or SVG if you prefer, but PNG
  is simplest).
- **Size:** ~400px on the longest side is plenty. Accreditation logos render ~56px
  tall; Coforge renders ~32px tall — they scale to fit automatically.
- Use the **official** version each organisation provides to members/partners —
  don't screenshot or crop from a website.
