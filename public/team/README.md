# Team photos

Photos shown on the About page. Name each file after the person in lowercase
with hyphens, e.g. `lane-mcewan.png`, `sarah-bolt.jpg` (jpg, jpeg, png or webp).
The About page picks the file up automatically; without one it shows initials.

Portrait photos work best. The card crops to a square from the top, so keep the
face in the upper part of the frame. Around 600px wide is plenty.
